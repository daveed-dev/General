# Cat & Khal's Porch Store

A cheerful, responsive one-page site for Cat and Khal's front-porch
store. The rotating menu describes the kinds of treats they sell
without promising specific items, prices, opening hours, or an address.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, set
the branch to `main` and the folder to `/(root)`, then save. GitHub Pages will
publish the site from `index.html`.

## Pull request checks and deployment

The **Storefront checks** workflow validates in-page links and local assets on
pull requests to `main`. Pull requests opened by `daveed-dev` from
`daveed-dev-catherine-khali-country-store` are set to squash auto-merge only
after those checks pass. Merging to `main` triggers the GitHub Pages deployment.
